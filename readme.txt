This autosplitter was originally made by elle, and was modified by me (Joeyfordayz) to add a few QOL features and small additions.

All previous features are still here, including: starting on new game or level entry, and ending on maul, vader, or ANH outro's. Splitting on every room is also still the same.

Newly added features include: ending on dooku outro, which is necessary for NoCut+NoShips runs. A toggleable automatic timer reset upon exiting to the main menu, a fixed kamino split when completeing the level in freeplay (yes it was broken before lmao).
And finally an adjusted new game timer start so it only functions while on the main menu. (for context it used to also fire a timer start when exiting a level while the timer is not running)
